# The xpm Core Library

A TypeScript Node.js module with the common code for xpm and xpm enabled projects.

## Project documentation

For information on how to install and use this project, please refer to the
[project website](https://xpack.github.io/xpm-lib-ts/).

## Project source

The source code of the current release is available on
GitHub as [xpack/xpm-lib-ts](https://github.com/xpack/xpm-lib-ts),
the [v5.0.0](https://github.com/xpack/xpm-lib-ts/tree/v5.0.0) tree.
