## Enhancements

- [[#9](https://github.com/xpack/xpm-lib-ts/issues/9)] - for more flexibility, 
  pass options to LiquidEngine constructor
- [[#10](https://github.com/xpack/xpm-lib-ts/issues/10)] - use the more 
  elaborate LiquidEngine in the InitTemplateBase class
- [[#11](https://github.com/xpack/xpm-lib-ts/issues/10)] - add asserts 
  to InitTemplateBase file functions
- [[#12](https://github.com/xpack/xpm-lib-ts/issues/12)] - make most 
  InitTemplateBase members and methods public enhancement
- [[#13](https://github.com/xpack/xpm-lib-ts/issues/13)] - use the same 
  substitution variables for xpm init templates
- [[#14](https://github.com/xpack/xpm-lib-ts/issues/14)] - add a new policy 
  topPropertiesXpmInitTemplate
- [[#15](https://github.com/xpack/xpm-lib-ts/issues/15)] - add policies 
  to InitTemplateBase
