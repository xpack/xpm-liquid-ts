### v4.0.0 (2026-01-??)

The API was updated following template instantiation implementation.
Only `initialise()` is now async for actions and build configurations.

### v3.0.0 (2026-01-03)

The API was significantly extended to use `XpmPackage` and `XpmLiquid*` classes.
The project was renamed **xpm-lib**, and support for CommonJS was dropped. 
The project is now ESM-only.

### v2.0.0 (2024-03-07)

The project was updated to support both ESM and CommonJS (dual mode).

### v1.x (2021-05-10)

First public release under the initial name **xpm-liquid**.
