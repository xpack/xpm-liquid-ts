This project provides a TypeScript Node.js ES6 module containing common 
functionality for **xpm** and **xpm-enabled** projects.

The module is primarily intended to be incorporated into projects
such as the `xpm` CLI application and the Visual Studio Code **xPack 
C/C++ Managed Build** extension.

## Features & Benefits

The module's primary purpose is to manage actions and build configurations 
with template substitution support via the Liquid template engine.

It also handles build configuration inheritance, enabling configurations 
to inherit properties and actions from parent configurations.
